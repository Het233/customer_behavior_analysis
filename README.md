# 📊 Customer Behavior Data Analyst Portfolio Project

An end-to-end, industry-standard data analytics workflow that mirrors the real responsibilities of professional analysts in modern business environments — from data preparation and modeling to insight generation, visualization, and stakeholder reporting.

---

## 📌 Project Overview

The goal of this project is to simulate a corporate-grade, end-to-end data analytics workflow — demonstrating the ability to translate raw data into strategic business intelligence.

| Stage | Tool | Description |
|---|---|---|
| ✅ Data Preparation, Modeling & EDA | **Python** | Clean and transform the raw dataset for analysis |
| ✅ Data Analysis | **SQL** | Simulate business transactions and query customer segments, loyalty, and purchase drivers |
| ✅ Visualization & Insights | **Power BI** | Build an interactive dashboard highlighting key patterns and trends |
| ✅ Reporting & Presentation | **Report / Deck** | Summarize key findings and business recommendations for stakeholders |

---

## 🛠️ How to Use This Project

### 1. Clone the repository

```bash
git clone https://github.com/amlanmohanty1/customer-trends-data-analysis-SQL-Python-PowerBI.git
cd customer-trends-data-analysis-SQL-Python-PowerBI
```

### 2. Open the Jupyter Notebook

Open `Customer_Shopping_Behavior_Analysis.ipynb`. This notebook covers:

- Data import
- Data exploration
- Data cleaning
- Connection to a SQL database

### 3. Load data into SQL

Load the cleaned data from the Python notebook into MySQL / PostgreSQL / MS SQL Server:

- Create a database in SQL
- Run the Python code to load data into the SQL database
- Open `customer_behavior_sql_queries.sql`
- Answer business questions using SQL queries

### 4. Connect SQL to Power BI

- Open `customer_behavior_dashboard.pbix`
- Build an interactive dashboard in Power BI

### 5. Create the report and presentation

- Write the project report
- Build a presentation deck (e.g., using Gamma AI)
